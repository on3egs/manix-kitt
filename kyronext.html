KYRONEXT
STUDIO — TELECHARGEUR AUDIO & LECTEUR LOCAL

[ SYSTEME.DESCRIPTION ] Application desktop legere pour telecharger des pistes audio depuis YouTube et les ecouter dans une bibliotheque locale. Pensee pour usage personnel, dans le strict respect des droits d'auteur et des conditions d'utilisation des plateformes sources.

TELECHARGER LINUX PC ↓ TELECHARGER WINDOWS ↓ CODE SOURCE GITHUB →
[ TERMINAL.INSTALL ]

Linux PC 64-bit Intel/AMD — apres telechargement : chmod +x Kyronext-Studio-linux-x86_64, puis ./Kyronext-Studio-linux-x86_64. Jetson / ARM64 necessite un build Linux ARM64 separe.

CARACTERISTIQUES
MODULES ACTIFS

CE QUE FAIT KYRONEXT

[ MODULE.01 ]
TELECHARGEMENT AUDIO
Recupere la piste audio d'une video YouTube en format optimise pour ecoute locale. Choix de qualite, metadonnees automatiques.
[ MODULE.02 ]
BIBLIOTHEQUE LOCALE
Organise les fichiers telecharges, recherche rapide, listes de lecture personnalisees, persistance entre sessions.
[ MODULE.03 ]
LECTEUR INTEGRE
Ecoute directe dans l'application sans dependance externe. Controles play / pause / next / shuffle / repeat.
[ MODULE.04 ]
CONFIDENTIALITE TOTALE
Tout reste local sur la machine. Aucune donnee envoyee a un serveur tiers. Pas de tracking. Pas de compte requis.
